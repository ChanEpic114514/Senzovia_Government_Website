# 卡谋语版翻译与维护

语言标记为 `art-x-kamotish`，路径为 `/art-x-kamotish/`。这是 `art` 加私用子标记，不冒用其他自然语言代码。

## 翻译来源与范围

以本仓库简体中文为对照稿，保持原有页面、章节、段落、条目和锚点结构。教育政策 195 个文本字段、科研政策 274 个、自由与平等机会政策 257 个均提供对应译文；基础内容、表单、信息处理说明、检索状态和六种展示脚本的文字也已翻译。文化、治理、重建的可编辑占位模板各有 8 个字段，仍不发布为政策全文。

语法参照用户提供的《标准卡谋语》融合修订版六单元及《全书总测试与附录》。字素、拟素与基础汉字混用；动作句使用系动词及 C 时态标记，领属使用 `\e\3`，修饰使用 `\ha`。借词按合法音节转写，保留 ESX、AI、LGBTQ+、网站地址、邮箱和文献编号等标识。

政策继续作为提案呈现。情态命题通过 `\e…\hou\2` 收束，外层说明为提案，避免直接将正式句末接在情态后。保留年龄、学制、科目数量、国籍与收入条件、例外及隐私告知；权利政策中的宗教监管、处罚、证据及程序要求也依原文翻译。

## 显示与编辑

JSON 中保存可编辑的卡谋语输入源码。构建时将字素和拟素转换为本地 SVG 字形，汉字保留为文本；所有页面复用一个字形文件。浏览器原生选单、占位文字、页面标题及辅助文字采用可读拼写，因为这些位置不能嵌入 SVG。

搜索保留完整的字素命令及音节，摘要在句号处截取，不拆开声调或从句源码。全文下载为卡谋语输入源码，可在兼容的卡谋语编辑器中继续校订；打印使用已经显示的字形。

渲染器来自用户的 Kamotish Input Method 项目，按其 MIT 许可随附于 `dist/assets/kamotish-LICENSE.txt`。构建使用 Node.js，不加载远程字体或渲染服务。

## 校验与复核边界

`tests/kamotish.py` 检查文本字段对应、缺译回退、字素与音节能否渲染、数字分隔、邮箱相邻语法、静态字形、页面与全文下载覆盖。`verify.py` 检查八语链接、搜索索引及原始国旗；`prepare_pages.py` 检查 GitHub Pages 项目路径。

自动检查能证明覆盖和显示完整，不能证明每一句语法与译意都无误。本版是完整译文初稿，尚未经语言创作者逐句终审；抽象复合词和长从句尤其需要人工复核。译文的内容判断应对照上述中文政策，不将可渲染等同于语言正确。
